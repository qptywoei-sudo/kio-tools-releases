# Bogo Tools

This branch contains the exact corresponding source for the Bogo Tools 4.6.23 r2 candidate. The snapshot is verified against the source archive listed in `bogo-tools-4.6.23-source.json`.

The candidate preserves existing signed update identities and adds an exclusive macOS bundle name migration after the original updater completes. Fresh Windows and macOS GUI acceptance is pending. This branch does not change the stable update channel.

Original copyright notices, licenses and technical compatibility identifiers are preserved. Private data, credentials, runtime packages and the private implementation history are excluded.
