# Bogo Tools

This branch contains the exact corresponding source for the Bogo Tools 4.6.23 r4 candidate, verified against the actual source archive in `bogo-tools-4.6.23-source.json`.

The Windows portable extractor preserves UTF-8 archive filenames using the existing system .NET ZIP reader and retains backups when repairing incomplete managed files. Bogo artwork and pale orange controls, compatibility identifiers, private user paths and the existing signed macOS update name migration are preserved. Fresh Windows and macOS R4 product acceptance remains pending. The stable update feed is unchanged.

Original copyright and license notices remain. Credentials, private data, runtime packages and private implementation history are excluded.
