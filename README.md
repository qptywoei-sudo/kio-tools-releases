# Bogo Tools

This branch contains the exact corresponding source for the Bogo Tools 4.6.23 r3 candidate, verified against the source archive in `bogo-tools-4.6.23-source.json`.

Bogo colors apply to login, settings and local tool controls, including light and dark preferences. Document, media, SVG and user colors retain their original behavior. Existing signed update identities and the guarded macOS app name migration are preserved. Fresh Windows and macOS R3 GUI acceptance is pending; this branch does not change the stable update channel.

Original copyright notices, licenses and technical compatibility identifiers are preserved. Private data, credentials, runtime packages and the private implementation history are excluded.
