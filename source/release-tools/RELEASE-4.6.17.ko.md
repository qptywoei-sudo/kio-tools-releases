# KIO Tools 4.6.17

이미지 번역에서 원문이 남거나 번역문이 지나치게 커지던 처리를 개선했습니다.

- 이미지 번역은 GPT-6.1 Sol / medium을 사용합니다. 연결한 계정의 모델 목록에 해당 모델이 없으면 명확히 알리며 다른 모델로 바꾸지 않습니다.
- Outlook 메일의 제목, 본문, 서명, 링크, 표의 각 셀을 구분하도록 인식 지침을 보강했습니다.
- 원문 글자와 안티앨리어싱 가장자리를 제거하고, 흰색·회색 배경 및 완만한 그라데이션을 주변 픽셀로 복원합니다. 복잡한 배경은 번들 OpenCV의 국소 인페인팅으로 처리합니다.
- 번역문은 원문 글자 크기를 기준으로 배치하고, 영역에 맞춰 줄바꿈·축소합니다. 짧은 번역문을 큰 글자로 확대하지 않습니다. 굵기·색·정렬을 반영합니다.
- 번역이 필요 없는 주소·번호·동일한 글자는 원래 픽셀을 유지합니다. 원본 해상도, 투명도, 글자 영역 밖의 픽셀을 보존합니다.
- 기존 텍스트 번역과 번역 이미지 PNG 저장·복사를 유지합니다.

재현 검증: 개인 메일을 사용하지 않은 Outlook 형태의 메일, 회색 표, 글자 색 번짐, 가로 그라데이션, 짧은/긴 번역문, CJK 줄바꿈, 투명도, 모델 선택·미지원 계정 처리를 검사했습니다. 재현 이미지의 번역·영역 정보는 고정 입력입니다. 이 Mac의 ChatGPT 계정은 연결되어 있지 않아 실제 계정 추론 및 사용자가 문제를 겪은 메일은 검증하지 못했습니다. 실제 Windows GUI 실행과 이전 버전의 설치·재시작도 미검증입니다.

공식 모델 정보: https://developers.openai.com/api/docs/models/gpt-6.1-sol
배경 복원 참고: https://docs.opencv.org/4.12.0/d7/d8b/group__photo__inpaint.html
