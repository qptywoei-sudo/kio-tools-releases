# KIO Tools 4.6.18

ZIP 압축을 풀고 KIO Tools 아이콘 하나를 열면 됩니다.

- Mac: `KIO Tools.app` 하나만 포함합니다. 실행에 필요한 도구, 소스와 라이선스는 앱 안에 있습니다.
- Windows: `KIO Tools.exe` 하나만 포함합니다. 처음 실행할 때 검증한 내장 구성요소를 사용자 전용 앱 폴더에 준비하고 실행합니다. 별도의 관리자 설치나 프로그램 다운로드가 필요하지 않습니다. Windows 10 (1803) 이상이 필요합니다.
- macOS 14 이상에서 영역·모니터·창 캡처를 앱 내부 ScreenCaptureKit으로 처리합니다. 오래된 권한 사전검사 값만으로 캡처를 차단하지 않습니다. 화면 녹화도 실제 캡처 API의 권한 결과를 사용합니다.
- Mac 빌드의 지정 서명 요건을 유지하는 로컬 코드 서명으로 변경했습니다. 이전 임시 서명과 달라 처음 한 번 새 앱의 화면 기록 승인이 필요할 수 있습니다. Apple Developer ID와 공증은 포함되지 않습니다.
- 베트남어, 영어, 한국어, 일본어, 중국어 번체·간체의 연결 안내 누락을 보완하고 ZIP 실행 안내를 통일했습니다.
- 기존 설정과 개인 파일, 서명 검증을 사용하는 앱 내 업데이트를 유지합니다. 고객용 ZIP과 업데이트용 ZIP은 별도이며 둘 다 같은 앱과 구성요소를 포함합니다.

검증: 독립 UI 타입 검사와 6개 언어 테스트, Mac arm64/x86_64 컴파일 및 네이티브 캡처의 기하·취소 검사, Windows x64 컴파일, 패키지의 민감정보·경로·버전 검사, ZIP 내부 최상위 항목 검사와 Windows 내장 페이로드 해시 검증을 실행합니다. 실제 Windows 화면 실행과 모든 컴퓨터의 최초 권한 승인은 이 Mac 빌드 검사로 확인할 수 없습니다.

계정 연결: 같은 KIO 계정의 ChatGPT 연결을 서버의 계정별 암호화 저장소와 연동합니다. 일반 KIO 로그아웃은 ChatGPT·Drive 연결을 지우지 않습니다. 다시 로그인한 Tools는 연결을 자동 복원합니다. 연결 해제는 웹·모든 Tools에 적용되며, 해제 전의 늦은 인증 응답이나 토큰 갱신이 연결을 되살리지 못합니다. ChatGPT 갱신은 서버의 버전 잠금으로 직렬화하고 브라우저에 갱신 토큰을 보내지 않습니다. 웹에서 새 ChatGPT 연결과 AI 추론을 시작하려면 OpenAI가 승인한 웹 서비스용 앱 등록 설정이 필요합니다. 앱 등록이 없는 운영 환경을 사용 가능으로 표시하지 않습니다.

중복 실행: Mac의 네이티브 요청 폴더를 실행 중인 앱별로 분리했습니다. 예전 앱이 다른 폴더에서 켜져 있어도 수정 앱의 캡처 요청을 대신 받아 권한 오류를 돌려주지 않습니다. 기존 업데이트 확인용 상태 표시는 유지합니다.
