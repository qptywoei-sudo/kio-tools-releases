# KIO Tools 4.6.22

- ChatGPT 플랜 승인 후 연결 결과가 로그인 실패로 바뀌던 오류를 수정했습니다.
- 승인된 계정의 기본 버튼은 연결 확인입니다. 재인증은 저장된 등록 정보를 재사용하고, 다른 계정 추가에서만 새 등록을 시작합니다.
- 권한을 거절했거나 인증이 만료된 기존 연결도 같은 등록 정보로 다시 승인할 수 있습니다.
- 이미지 번역 상단에 원문 복사·번역본 복사를 추가했습니다. 원문은 번역 중에도 이미지로 복사할 수 있으며 별도로 표시하지 않습니다. 번역본 복사는 이미지가 완성된 뒤 사용할 수 있습니다.
- 창을 닫거나 스캔·계정·결과가 바뀐 뒤 늦게 도착한 이미지의 복사·저장을 차단합니다.

원문과 번역 이미지는 기존 메모리 세션에서만 사용하며, 계정 설정과 기존 개인 자료는 유지합니다.

이 폴더의 수정본은 로컬 검증용입니다. 실제 Windows의 계정 승인·AI 요청·클립보드 동작은 Windows에서 별도로 확인해야 합니다.
