# KIO 컨트롤 4.4.3 검증 보고

작성일: 2026-10-13. Windows 실행 파일에 반영. 개인 인증정보는 Windows 사용자 프로필에 유지하며 배포 ZIP에는 포함하지 않음.

## 구현

- 번역의 보낸 사람과 발음을 `이름 / 발음` 한 줄에 표시하고 아래에 원문·번역을 배치. 전체 복사도 같은 3줄 구조.
- 대화에서 댓글/답글 미리보기 안내, 사진 개수, 읽음 숫자, 시간 등 화면 표시 제외. 발신자 이름은 유지. 문서 제목·날짜·숫자와 실제 메시지 본문의 숫자는 제외하지 않음. 단어를 기계적으로 지우는 정규식 필터는 사용하지 않음.
- 답장 대상 선택 → 자동 답장 생성. 원하는 내용을 직접 지정하는 방식도 유지. 대상 변경 시 이전 초안 제거. 상대 언어가 불명확하거나 본인 메시지인 경우 생성 제한. 자동 전송은 하지 않고 복사해 사용.
- 답장 생성은 기존 번역 세션의 메시지와 대상 언어를 재사용. 이미지 재전송 없음. 중복 클릭은 하나의 요청으로 제한.
- AI 9개 기능(번역, 글자 추출, 오류 해결, 글 요약, 표 추출, 문장 교정, 수식 도움, 일정 추출, 답장·글쓰기)의 여백과 도구 크기 축소. 복사 아이콘을 텍스트 오른쪽에 배치. 텍스트 부분 선택 유지.
- 도장 날짜 형식 10종: 년-월-일, 년/월/일, 년.월.일, 일/월/년, 일-월-년, 일.월.년, 월/일/년, 월-일-년, 한글, 숫자 연속. 기존 도장은 기존 표기 유지. 배치한 각 도장은 독립 수정.
- 추천 모델 GPT-6 Luna, 추론 low. 설정에서 자동 추천/none/low/medium 선택. 계정에서 지원·검증된 항목만 표시. 별도 API 키 및 유료 API 전환 없음.

## 실제 구독 모델 비교

기존 공식 구독 연결·플랜 승인·화면 전송 동의 확인. 계정 모델 목록에서 `gpt-6-luna`와 이미지 입력 지원 확인. low/medium은 계정 목록에 표시되며 none도 실제 호출 성공 확인. 실제 구독 요청 사용. 이미지와 대화 내용·인증 토큰은 성능 보고 파일에 저장하지 않음.

같은 사용자 제공 이미지, 마지막 번역 지시로 각 수준 3회씩 순서를 바꿔 비교한 요청 전체 처리 시간:

| 추론 | 평균 | 중간값 | 최댓값 | 응답 성공 | 이름·본문 중심/화면 표시 제외 |
|---|---:|---:|---:|---:|---:|
| none | 6.237초 | 5.295초 | 8.837초 | 3/3 | 3/3 |
| low | 4.704초 | 4.661초 | 5.016초 | 3/3 | 3/3 |
| medium | 6.399초 | 5.060초 | 9.242초 | 3/3 | 3/3 |

low는 이번 최종 반복에서 가장 빠르고 변동도 작아 기본 추천으로 적용. medium은 일부 초기 반복에서 10~13초였고 마지막 반복 평균은 6.399초로, 항상 같은 지연이 발생하는 것은 아님. 계정 부하·서비스 상황·이미지에 따라 달라짐. 위 시간에는 영역 드래그와 팝업 렌더링 시간이 포함되지 않음.

수정 전 1회 측정은 8.203초, 불필요한 표시가 포함된 5개 블록. 수정 후 마지막 9회는 모두 실제 메시지 1개 블록으로 출력. 초기 측정 스크립트의 콘솔 인코딩 오류가 응답 성공 이후 발생해 초기 JSON의 ok=false로 기록되었으나 API 응답은 완료됐고 블록 수와 처리 시간을 수집했음. 이 단일 기준점으로 일반적인 속도 향상률을 단정하지 않음.

### 정확도와 실패 사례

- 이름, 이름 발음, 베트남어 본문의 칩 누락 의미와 한국어 번역 유지 확인.
- 작은 캡처의 식별자 O/Q, 점/쉼표, chip/chíp 표기에 수준별·반복별 판독 차이 존재. 입력 메시지에 사용자가 적은 NO01과 캡처 글자의 NQ01 판독도 차이가 있었음. 완전한 문자 일치나 100% 정확도를 주장하지 않음. medium에서도 이 차이가 일관되게 해소되지 않음.
- 초기 엄격한 OCR 정답 비교는 문장부호·철자 차이로 실패했으며, 이 결과는 성공으로 바꿔 기록하지 않음. 마지막 별도 회귀 측정에서도 식별자 완전 일치 검사는 실패했음. 발신자 표시/불필요한 화면 표시 제거/본문 의미/답장 동작은 별도로 확인.
- 개발 중 none/low에서 aiInvalidResponse가 간헐적으로 발생. 답장 대상 인덱스를 0부터 시작한다고 명시한 마지막 반복 9회는 모두 완료. 불완전 응답을 성공으로 표시하거나 무한 재요청하지 않음.
- 문서 이미지의 제목과 6, 날짜 2026-10-20, 2:30, 수량 2, 참조번호를 none/low/medium 모두 보존. 각각 7.522/7.354/8.673초.
- 실제 자동 답장: low, 베트남어, 3.726초. 한국어 뜻도 반환. 요청 1회, 이미지 입력 0개. 실제 상대방에게 전송하지 않음.

- 네이티브 Windows 빌드 및 SharedHostPolicy 자체 검사 통과.
- 실제 Chromium에서 AI 9개 화면을 각각 열어 결과 표시·복사·가로 넘침·React 오류 확인. 자동 답장의 대상 변경, 직접 의도 지정, 중복 클릭 방지 확인. 이 UI 검사는 고정 테스트 응답을 사용하며 9개 기능 모두의 새 실서비스 추론 검증을 뜻하지 않음.
- 도장 날짜 선택 10개가 서로 다른 실제 캔버스 미리보기로 변경됨. 문서에 배치한 도장 2개가 독립적인 날짜 형식을 유지함.
- 실제 실행 중인 앱 4.4.3, 네이티브 연결, 모니터 2대, 기존 ChatGPT 계정 연결·플랜 승인 유지, 자동 추천 low 확인.
- ZIP CRC 및 실행 파일 동일성 확인. ZIP을 별도 폴더에 풀어 내장 Python 백엔드/새 UI/FFmpeg 실행 확인. 새 프로필에 ChatGPT 로그인 정보가 없음을 확인. 압축 해제본의 별도 네이티브 창 테스트는 하지 않았고, 동일한 바이너리를 실제 프로그램 위치에서 실행 검증함.
