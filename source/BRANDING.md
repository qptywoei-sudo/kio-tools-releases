# Bogo Tools — 4.6.23

The owner explicitly approved creating a new Tools icon in the same family as
Bogo's 14 program icons on 2026-10-26. It is a separate Tools original; none of
the 14 approved program PNGs is borrowed or cropped. The new master and exact
SHA-256 provenance are recorded in bogo-tools-artwork.json. The PNG master is
copied without changing its design or orange color. ICO, ICNS, browser sizes and
the static startup PNG are build derivatives of that master.

Visible product names use Bogo Tools. Program chrome uses #FFF3E8 headers,
#FFFAF6 backgrounds, #FFE7D4 selection, #F1D3BD borders and #342B26 text.
Media/document content colors and saved user values remain unchanged.

KIOControl.exe, local.galaxycontrol.portable, KIO.Tools.Desktop, private state
paths, OAuth/extension identities, fixed Drive pins and the Ed25519 update key
and feed remain stable. Signed update roots stay KIO-Control-Windows/Mac.
Customer ZIP/app/launcher names use Bogo Tools. Existing app installation paths
remain valid during upgrades; localized bundle display metadata supplies the
new name without moving user files or credentials.

The old approved KIO source artwork remains in version control and is retained
below as historical provenance. It is no longer referenced by the current UI.
Signing and publication policy is unchanged: local signing is not Apple
notarization or a Windows publisher certificate, and no build is described as
executed on another OS without actual OS evidence.
