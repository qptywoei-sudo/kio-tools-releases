Independent desktop UI: Node 22+; cd desktop-ui; npm ci; npm run typecheck; npm test; npm run build. No ADMIN checkout, credentials, remote server or deployment is required. Output defaults to desktop-ui/dist. Native Mac: sh mac/build-mac.sh on macOS with Xcode. Sign a completed local Mac app bundle after all resource changes with python3 mac/sign-local.py --setup /path/to/GalaxyControl.app; subsequent updates reuse that private local identity. The signing keychain stays outside this archive. Public distribution requires Apple-issued signing and notarization. Native Windows: sh windows/build-windows.sh with Zig 0.16. Python dependencies are listed in engine/requirements.txt and engine/agent-dependencies.json. Third-party corresponding-source archives and licenses remain alongside this archive in the portable payload. ADMIN source, backend, migrations, environment files, user uploads and private agent state are excluded.
